# GitLine website

GitLine helps you understand the history behind your code. See who changed a line, when it changed and what the commit was about, then open the change history directly from your editor.

This repository contains the GitLine product website. It introduces the plugin, shows how it fits into everyday development and provides installation guidance, interface examples and answers to common questions.

GitLine is a free plugin for IntelliJ Platform IDEs. Both the website and the plugin interface are available in English and Russian.

- **Russian version:** [GitLine in Russian](https://dmitry-osin.github.io/getgitline/)
